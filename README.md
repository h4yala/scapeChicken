## <a name="english-version"></a> English Version

**Scape Chicken** is a 2D game developed in Python using the Pygame library. The goal is to survive the attacks of angry chickens while collecting fruits to craft jellies and advance to the next level!

### 🎮 How to Play
*   **Arrow Keys:** Move the farmer around the screen.
*   **Objective:** Collect 3 fruits to craft 1 Jelly Jar.
*   **Progression:** Craft the required amount of jellies to advance. The game has 6 levels, getting progressively harder!
*   **Watch out:** Avoid the chickens! If you get hit 3 times, it's Game Over.

### 🛠️ Technologies
*   **Python 3**
*   **Pygame** (2D Engine)
*   **Architecture:** Object-Oriented Programming (Classes, Inheritance, and Factory Pattern)

## <a name="versão-em-português"></a> Versão em Português

# 🐔 Scape Chicken - HayFarm

**Scape Chicken** é um jogo 2D desenvolvido em Python utilizando a biblioteca Pygame. 
O objetivo é sobreviver aos ataques das galinhas raivosas enquanto coleta frutas para fabricar geléias e avançar de nível! 

Este projeto foi desenvolvido como trabalho prático para a disciplina de Linguagem de Programação Aplicada.

## 🎮 Como Jogar
*   **Setas do Teclado:** Movimentam o fazendeiro pela tela.
*   **Objetivo:** Colete 3 frutas para fabricar 1 Pote de Geléia.
*   **Progressão:** Forme a quantidade de geléias exigida pelo nível para avançar. O jogo possui 6 fases, ficando progressivamente mais difícil!
*   **Cuidado:** Evite as galinhas! Se você for atingido 3 vezes, é Game Over.

## 🛠️ Tecnologias Utilizadas
*   **Python 3**
*   **Pygame** (Engine 2D)
*   **Arquitetura:** Orientação a Objetos (Classes, Herança e padrão Factory)
